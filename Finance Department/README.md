# Group assignment submission and mark capture · UCT Finance

**One student submits for the group, and the marker captures one shared mark, instead of entering the same mark for every member.**

| | |
|---|---|
| **Role** | Head Tutor, FTX1005F |

| **When** | 2026 |
| **Status** | Trialled in FTX1005F; adopted for FTX3044F; planned for FTX4056S |

## In short

- **The problem:** groups did the work together, but each member's mark was entered separately, so one decision was typed five times per group.
- **The idea:** use a group-assignment feature Amathuba already had (other courses, such as Computer Science, were using it), instead of building anything new.
- **The trial:** tested in FTX1005F with two colleagues, with the old process kept as a backup.
- **The result:** about **80% fewer mark entries**. For roughly 150 students in groups of five, that's about 150 entries down to 30. This is a count of entries, not measured time.
